# SauceDemo — Manual QA Practice

This is my first manual testing project. I tested the SauceDemo shopping website to practice writing test cases, checking checkout functionality, and investigating unexpected behavior.

I tested adding and removing products, checking cart totals, and entering different types of information during checkout.

I documented my results in an Excel spreadsheet and wrote a report about a possible input validation issue I found.

Testing environment: Safari on iPadOS 26.6.2
